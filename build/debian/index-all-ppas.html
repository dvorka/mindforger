MindForger Debian PPA repositories

MindForger provides Personal Package Archive (PPA) repositories for the following Debian releases - there is not one repository for all Debian releases, but a repository per Debian release:

@RELEASES@
Debian releaseCodenameStatusLatest MindForger

Click the Debian release for installation steps.

Installation

Replace CODENAME with your Debian release codename (. /etc/os-release; echo $VERSION_CODENAME) from the table above:

# create directory for APT repository keys (if it does not exist)
sudo install -d -m 0755 /etc/apt/keyrings
# download MindForger GPG key and store it in the binary format used by APT
wget -qO- @KEY_URL@ | gpg --dearmor | sudo tee /etc/apt/keyrings/mindforger.gpg > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/mindforger.gpg] https://www.mindforger.com/debian-ppa/CODENAME CODENAME main" | sudo tee /etc/apt/sources.list.d/mindforger.list
sudo apt update
sudo apt install mindforger

Signing key

All repositories are signed by MindForger key:

  • fingerprint: @KEY_FINGERPRINT@
  • public key: @KEY_URL@

Check the fingerprint of the downloaded key:

wget -qO- @KEY_URL@ | gpg --show-keys --with-fingerprint

Notes:

  • 2026 key refresh: self-signatures of the key were refreshed from SHA-1 to SHA-512, because Debian 13 Trixie apt rejects keys w/ SHA-1 self-signatures. The key and its fingerprint did not change. If apt update reports that the signing key is not bound or SHA1 is not considered secure, download the key again using the installation steps above.
  • apt-key used by older installation instructions is deprecated and it is not available on Debian 13 Trixie - use signed-by keyring as shown above.
