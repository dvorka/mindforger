MindForger Debian "@DISTRO@" PPA repository

This is Personal Package Archive (PPA) for MindForger and Debian "@DISTRO@" release (all MindForger Debian PPAs).

Download the key which is used to sign the repository:

# create directory for APT repository keys (if it does not exist)
sudo install -d -m 0755 /etc/apt/keyrings
# download MindForger GPG key and store it in the binary format used by APT
wget -qO- @KEY_URL@ | gpg --dearmor | sudo tee /etc/apt/keyrings/mindforger.gpg > /dev/null

... add the repository:

echo "deb [signed-by=/etc/apt/keyrings/mindforger.gpg] https://www.mindforger.com/debian-ppa/@DISTRO@ @DISTRO@ main" | sudo tee /etc/apt/sources.list.d/mindforger.list

After that you can install MindForger as any other software package:

sudo apt update
sudo apt install mindforger

Signing key fingerprint: @KEY_FINGERPRINT@ - see signing key notes if apt update reports a key problem.
