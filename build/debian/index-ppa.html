MindForger Debian "DISTRO" PPA repository

This is Personal Package Archive (PPA) for MindForger and Debian "DISTRO" release.

Download the key which is used to sign the repository:

      sudo install -d -m 0755 /etc/apt/keyrings
      wget -qO- https://www.mindforger.com/gpgpubkey.txt | gpg --dearmor | sudo tee /etc/apt/keyrings/mindforger.gpg > /dev/null

... add the repository:

      echo "deb [signed-by=/etc/apt/keyrings/mindforger.gpg] https://www.mindforger.com/debian-ppa/DISTRO DISTRO main" | sudo tee /etc/apt/sources.list.d/mindforger.list

After that you can install MindForger as any other software package:

      sudo apt update
      sudo apt install mindforger
